# HR-Analytics-Employee-Performance-Overview-Tableau

## Project objective
The objective of this project is to develop an interactive Human Resources Analytics Dashboard using Tableau to analyze employee data and generate meaningful workforce insights. The dashboard aims to track key HR metrics, understand department and state-wise employee distribution, analyze hiring trends, explore gender and job-role diversity, and evaluate employee age and tenure. It enables users to interact with the data through dynamic filters and visualizations, supporting effective workforce analysis and data-driven decision-making.

### Process 
- Collected employee and HR-related data containing details such as department, job title, gender, state, hiring date, termination date, age, and tenure.
- Checked the dataset for missing values, duplicate records, inconsistent entries, and incorrect data formats.
- Organized and prepared the data for analysis by creating the required fields and ensuring appropriate data types.
- Analyzed employee status, workforce distribution, hiring trends, gender diversity, job roles, employee age, and tenure.
- Created key performance indicators such as total employees, hired employees, terminated employees, active employee percentage, average age, and average tenure.
- Developed charts to represent department-wise, state-wise, gender-wise, and job-title-wise employee distributions.
- Combined KPIs, charts, and tables into an interactive Tableau dashboard.
- Added filters for department, state, year of hire, gender, and job title to enable detailed analysis.
- Identified important workforce patterns and trends through interactive visualizations.
- Designed the dashboard with a clear layout to make HR information easy to understand and explore.

### Project Insights
- The dashboard provides a clear overview of the organization’s overall workforce and employee status.
- Department-wise analysis highlights differences in employee distribution across various business functions.
- State-wise workforce analysis shows the geographical distribution of employees and identifies locations with higher employee concentration.
- The hiring trend analysis helps identify changes in recruitment activity across different years and months.
- Gender analysis provides insights into workforce diversity across the organization.
- The job title analysis shows how employees are distributed across different roles and identifies roles with higher workforce representation.
- The dashboard highlights differences in job-role distribution by gender, providing a deeper view of workforce composition.
- Average age and tenure metrics provide an overview of employee demographics and experience levels.
- Interactive filters allow users to analyze workforce patterns based on department, state, year of hire, gender, and job title.
- Overall, the dashboard demonstrates how Tableau can transform HR data into clear, interactive, and meaningful workforce insights.

## Final Conclusion
The Human Resources Analytics Dashboard successfully transforms employee data into meaningful and interactive visual insights using Tableau. It provides a comprehensive view of workforce distribution, employee status, hiring trends, gender diversity, job roles, age, and tenure. The interactive filters make it easier to explore specific employee segments and identify workforce patterns. Overall, this project demonstrates the practical application of data analysis, KPI development, data visualization, and dashboard design to support effective HR analysis and data-driven decision-making.
